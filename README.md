# GrooveForge

Record a beatbox pocket in the browser. GrooveForge finds the kicks, snares, and hats, locks them to a grid, dresses a bassline, and plays it back as a studio drum take.

Flavors: Funk, 808, House, Boom Bap, Afro. Compare your mouth against the printed take, edit the step grid, and save a WAV.

## Run

```bash
npm install
npm run dev
```

Then open the URL the dev server prints. Play starts the demo pocket. Record uses the microphone. Upload accepts an audio file if the mic is blocked.

Built with TypeScript, React, and the Web Audio API.
